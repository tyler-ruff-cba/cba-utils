# Documentation

CBAUtils documentation is the operational reference for office procedures and CBA software.

## Getting Started

Guides for new users, common workflows, and general CBAUtils usage.

## Office Procedures

Step-by-step procedures for recurring office tasks.

## Web Apps

Documentation for Check Runs, A/R Processor, and future web applications.

## Desktop Apps

Installation, usage, troubleshooting, and maintenance information for CBA desktop software.

## Application Documentation

Application-specific guides should live alongside the relevant workflow so employees can find instructions without searching through unrelated procedures.
