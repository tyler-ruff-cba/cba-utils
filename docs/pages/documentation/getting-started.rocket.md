# Getting Started

## CBAUtils at a Glance

Use CBAUtils as the starting point for CBA software and office procedures.

- **Web Apps** are launched directly in a browser.
- **Desktop Apps** are installed on the workstation and maintained through their application pages.
- **Documentation** contains procedures and application instructions.

## Finding an Application

Start from the Web Apps or Desktop Apps collection, then open the application's page for its launch/download link and supporting information.
